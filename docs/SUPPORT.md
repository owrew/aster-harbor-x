# Support Aster Harbor

Maintainer: **Awais Ali Rafaqat**.

Official support page supplied by the maintainer:

https://ko-fi.com/Z3J629YD9V

![Ko-fi QR code](images/ko-fi-qr.webp)

The supplied QR was decoded locally and points to the same profile, with Ko-fi's QR query parameters. It was copied without image edits.

The extension uses the supplied light-blue color, #72a4f2, in a small locally packaged support control. The control appears in the in-page panel, popup, library, activity, and settings pages. Its QR image is loaded from the extension only when expanded.

No remote Ko-fi widget JavaScript, embedded checkout, automatic payment, payout secret, or payment-provider API key is included. Clicking the link opens the public provider page with its own terms and privacy policy.

Users can clear or change the optional creator-support URL in Settings. A changed URL hides the original profile's QR to avoid a mismatch.

This integration verifies the link/QR relationship, not the maintainer's identity verification, bank account, or payout approval. Support is optional and does not unlock a claimed store-certified or guaranteed-complete DM extractor.
